# **Carbonscio: Gaming for a Greener Planet**

**Carbonscio** (_coined from carbon conscious_) turns climate literacy into a game. With 3.5 billion people worldwide identifying as gamers, we use play to bridge the gap between "knowing" about climate change and "doing" something about it.

While over **80%** of adults in parts of Europe and North America possess basic climate literacy, African nations average just **37%**. Carbonscio meets this challenge by leveraging the global gaming market—a dominant industry with over **40%** of the world’s population participating in 2026. We aren't just teaching; we’re empowering a new generation of advocates to lead the charge in their own communities.

**Carbonscio** is built to ensure there are zero blockers to climate literacy. To encourage immediate engagement, users can play and learn **anonymously** on the website without the friction of creating an account.

## **Product Features**

*   **Interactive Quizzes:** A gamified approach to rapidly increasing climate literacy.  
*   **Impact Calendar:** Track daily activities and visualize carbon offset progress over time.  
*   **Transparency Database:** A curated directory of companies funding eco-sustainability—and a spotlight on those that aren't. Data is sourced from verified public records, with all [references](http://carbonscio-web.vercel.app/references) made accessible to the user.  
*   **Ask AI:** Get instant, accurate answers to climate-related questions via a custom Gemini AI integration.  
*   **Climate Wiki:** A comprehensive library of articles for deep-dive learning.  
*   **Inclusive Design:** High accessibility standards including customizable line height, spacing, and contrast settings to ensure the platform is usable for everyone, everywhere.

## **Technologies Used**

*   **Framework:** [React 18](https://reactjs.org/) with [Vite](https://vitejs.dev/)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Custom Brutalist Aesthetic)
*   **Icons:** [Lucide React](https://lucide.dev/)
*   **Routing:** [React Router DOM](https://reactrouter.com/)
*   **Data Integration:** Fetch API connecting to Google Apps Script (GAS) endpoints
*   **AI Integration:** Google Gemini AI
*   **Accessibility:** Custom Context-based settings (Dyslexic font, High Contrast, etc.)
*   **Translation:** Google Translate API

## **Setup Instructions**

To run this project locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/itsgbemi/carbonscio-web.git
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Start the development server:**
    ```bash
    npm run dev
    ```
4.  **Build for production:**
    ```bash
    npm run build
    ```
